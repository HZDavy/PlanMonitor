FAQ

常见疑问

会泄露我的 AK/SK 吗?

不会。本工具所有网络请求都直接发到 ark.cn-beijing.volcengineapi.com(火山方舟官方 API 域名),不经过任何第三方中转。

为什么体积 42 MB?

全部来自 PyQt5 自带的 Qt 运行库(launcher + GUI 引擎)。程序本身代码 < 100 KB,其他没有任何依赖。

支持多屏幕 / 高 DPI 吗?

支持。窗口锁宽 560px,跨屏位置自动记忆,1.75x / 2.0x 高 DPI 屏已测试通过。

可以改成 Agent Plan 吗?

API 路径一样,只需在配置里切换 action 参数(代码预留了扩展位)。
