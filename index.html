隐私与安全Privacy & Security

你的 AK / SK Your AK / SK 从不离开本机never leaves your machine

Coding Plan Monitor 坚持「本地优先、最小数据收集」。打开网络面板就能看到每一次出网请求 —— 除了官方 Coding Plan 接口，没有第二个目的地。 Local-first. Minimal collection. Open DevTools and watch every outbound request — the only destination is the official Coding Plan endpoint.

AK / SK 仅写到 config.jsonAK / SK in config.json

凭据以明文写到与程序同目录的 config.json。明文不推荐上传到仓库，请为本工具单独创建子账号。Credentials are saved in plaintext to config.json next to the exe. Don't commit it — use a dedicated sub-account.

HTTPS · 防重放HTTPS · anti-replay

所有请求走官方 TLS 端点，按火山引擎 Signature V4 规范生成签名：发 X-Date、X-Content-Sha256、credential-scope 以及针对请求体计算的 signature。All calls go over TLS to the official endpoint. Signed per Volcengine Signature V4 — X-Date, X-Content-Sha256, credential-scope and a signature computed over the request body.

只出一次网 · 不起本地服务One call · no local server

只调用官方 GetCodingPlanUsage 一次，失败不重试也不重传。关闭后只丢失内存中的数据。Only one outbound call: GetCodingPlanUsage. No local cache, no local server, no retries. Closing the app discards the in-memory data.

开源 · 全程可审Open source · fully auditable

纯 PyQt5 + requests 两个依赖，单文件入口 coding_plan_monitor.py。单文件易于审计，依赖清晰。Only PyQt5 + requests. Single coding_plan_monitor.py entry. Easy to audit, minimal dependencies.

离线可用 · 断网不崩Offline-resilient

网络异常时显示最后一次拉取的数字，状态栏标「请求失败」。恢复后下一轮定时器自动重试，不留存错误状态。On failure the HUD keeps showing the last values and shows a 'request failed' badge. The next timer tick retries — no stale error sticks around.

无埋点 · 无后台No telemetry · no background

应用不收集使用统计、不弹广告、不创建注册表项。关闭后只看下内存里的数据会被释放。No usage stats, no ads, no registry entries. Closing the app releases the in-memory data.
