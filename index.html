隐私与安全Privacy & Security

你的 AK / SK Your AK / SK 从不离开本机never leaves your machine

Coding Plan Monitor 坚持「本地优先、最小数据收集」。打开网络面板就能看到每一次出网请求 —— 除了官方 Coding Plan 接口，没有第二个目的地。 Local-first. Minimal collection. Open DevTools and watch every outbound request — the only destination is the official Coding Plan endpoint.

AK / SK 走系统 KeyringOS Keyring for AK / SK

SK 始终加密保存在 Windows Credential Manager / macOS Keychain，应用进程外不可读。明文只在内存里活过这一次请求。SK lives in Windows Credential Manager or macOS Keychain. Plaintext only exists in memory for the duration of one HTTP request.

HTTPS · 防重放HTTPS · anti-replay

所有请求走官方 TLS 端点，签名头带 nonce + 时间戳。Egress 抓包验证：除 volcengine.com 外零出网。All calls go over TLS to the official endpoint with nonce + timestamp signing. Verified by egress capture: zero outbound traffic outside volcengine.com.

本地优先 · 数据不出本机Local-first · never uploaded

用量快照只在本地 SQLite（默认关闭同步），导出文件由你决定去哪儿。关闭应用即彻底清理内存中的缓存。Snapshots live in local SQLite (sync off by default). You decide where exports go. Closing the app wipes the in-memory cache.

开源 · 全程可审Open source · fully auditable

PyQt5 + requests + pyqtgraph，单一入口 main.py。任何人 PR、任何人审。Pull request 通过 CI 自动构建并签名。PyQt5 + requests + pyqtgraph, single main.py entry. Anyone PRs, anyone reviews. PRs build & sign via CI automatically.

离线可用 · 断网不崩Offline-resilient

网络异常时浮窗继续显示最近一次快照，状态栏标红「离线」，恢复后自动续传，绝不假装在线。On network error the HUD keeps showing the last snapshot with a red 'Offline' badge — never pretends to be online.

零遥测 · 零广告Zero telemetry · zero ads

应用不收集使用统计、不弹广告、不写注册表幽灵项。卸载后只剩一个空文件夹，无残留。No usage stats, no ads, no ghost registry keys. After uninstall the folder is empty — nothing left behind.
