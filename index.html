安全Security

凭证不出本机,是底线,不是特性。Credentials never leave your machine. By design.

本地存储Local-only storage

AK/SK 仅写入本机用户目录,使用 Windows DPAPI 加密。Your AK/SK lives in your user profile, encrypted with Windows DPAPI.

最小权限Minimal scope

仅请求余额、用量、价格表接口。不读取聊天记录、文件、设置。Only balance, usage and pricing APIs. Never chats, files, or settings.

零遥测Zero telemetry

无埋点、无统计、无后台进程。退出即关停,联网仅在拉取数据时。No analytics, no background workers. Quitting kills the network too.

开源可审Auditable source

所有代码在 GitHub 公开,每一个网络请求都看得见。Every line of code is on GitHub. Every network call is visible.

FAQ

常见问题Common questions

这是怎么实现的?How does it work under the hood?
PyInstaller 把 PyQt5 程序打包成单文件 .exe,启动后用本地凭证请求 Coding Plan 接口,小窗口显示余额、预估与价格表。PyInstaller bundles the PyQt5 app into a single .exe. On launch it talks to the Coding Plan APIs using your local credentials, then renders a tiny HUD with balance, forecasts and prices.
可以用在公司账号上吗?Will it work with my company account?
可以。本工具仅请求余额、用量、价格表接口,不区分个人与企业。Yes. Only balance, usage and pricing endpoints are touched, regardless of account type.
会消耗额外的 token 吗?Does it burn extra tokens?
不会。所有接口都是只读的元数据查询,不会触发模型调用。No. All endpoints are read-only metadata queries, no model invocation.
凭证存在哪里,会泄漏吗?Where are credentials stored?
使用 Windows DPAPI 在用户目录加密保存,任何其他应用都无法读取,卸载即彻底删除。Encrypted via Windows DPAPI in your user profile. Unreachable to other apps. Removed on uninstall.
会联网做什么?What network calls does it make?
只向 volcengine.com 官方接口发起 HTTPS 请求,只读取余额、用量、价格。无任何第三方域名。Only HTTPS calls to volcengine.com for balance, usage and prices. No third-party domains.
为什么不直接做成网页?Why a desktop app instead of a web app?
因为网页无法在角落常驻浮窗、无法访问 DPAPI、也无法在不暴露凭证的前提下持续刷新余额。A web page can\\'t live in a corner, can\\'t use DPAPI, and can\\'t keep refreshing without exposing credentials.
